คำถามที่พบบ่อยและวิธีใช้งานแอปวันดีๆ

หัวข้อด่วน

🚀 เริ่มต้นใช้งาน 📝 การเขียนบันทึก 📸 รูปภาพและเสียง 🔍 ค้นหาและดูบันทึกเก่า ⚙️ การตั้งค่า 💾 ข้อมูลและความปลอดภัย 📧 ติดต่อเรา
🚀 เริ่มต้นใช้งาน
วิธีเปิดแอปครั้งแรกต้องทำอะไรบ้าง? ▾
  1. เปิดแอปวันดีๆ จาก App Store หรือ TestFlight
  2. แอปจะพาคุณผ่านขั้นตอนตั้งค่าเริ่มต้น เช่น ขนาดตัวอักษรที่ต้องการ
  3. เมื่อตั้งค่าเสร็จ คุณจะเห็นหน้าหลักพร้อมเขียนบันทึกได้ทันที
  4. ไม่ต้องสมัครสมาชิกหรือล็อกอิน — เริ่มใช้ได้เลย
ต้องต่ออินเทอร์เน็ตไหมเพื่อใช้งาน? ▾

ไม่จำเป็นเลยครับ/ค่ะ แอปวันดีๆ ใช้งานได้เต็มรูปแบบโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ทุกฟีเจอร์ทำงานออฟไลน์ได้ ไม่ว่าจะเป็นการเขียนบันทึก แนบรูป บันทึกเสียง หรือค้นหาบันทึกเก่า

📝 การเขียนบันทึก
วิธีเพิ่มบันทึกใหม่ทำอย่างไร? ▾
  1. แตะปุ่ม "เขียนบันทึก" หรือปุ่ม + ที่หน้าหลัก
  2. แอปจะเปิดหน้าบันทึกใหม่พร้อมวันที่ปัจจุบันโดยอัตโนมัติ
  3. พิมพ์หรือพูดบันทึกของคุณ (ดูวิธีบันทึกเสียงในหัวข้อถัดไป)
  4. เลือกอารมณ์ประจำวันได้ที่ด้านบน
  5. แตะ "บันทึก" เมื่อเสร็จแล้ว
ย้อนหลังไปเขียนบันทึกของวันที่ผ่านมาได้ไหม? ▾

ได้ครับ/ค่ะ สามารถเปิดปฏิทินและเลือกวันที่ต้องการแล้วแตะ "เพิ่มบันทึก" สำหรับวันนั้นได้เลย หรือจากหน้าหลักแตะที่วันที่แสดงอยู่เพื่อเปลี่ยนวันที่ก่อนเขียน

แก้ไขหรือลบบันทึกที่เขียนไปแล้วได้ไหม? ▾

ได้ทั้งคู่ครับ/ค่ะ เปิดบันทึกที่ต้องการ แล้วแตะปุ่ม "แก้ไข" ที่มุมขวาบนเพื่อแก้ไข หรือแตะ "ลบบันทึก" เพื่อลบออก (ระบบจะถามยืนยันก่อนลบ)

บันทึกอารมณ์ประจำวันทำอย่างไร? ▾

ขณะเขียนบันทึก มีแถบเลือกอารมณ์อยู่ด้านบน แตะเลือกสัญลักษณ์ที่ตรงกับความรู้สึกของคุณในวันนั้น ตั้งแต่ดีใจมากจนถึงเศร้า สามารถดูสรุปอารมณ์ย้อนหลังได้ที่หน้า "สรุป"

📸 รูปภาพและเสียง
วิธีเพิ่มรูปภาพในบันทึกทำอย่างไร? ▾
  1. ขณะเขียนบันทึก แตะปุ่มไอคอน 📷 กล้อง หรือ 🖼️ รูปภาพ
  2. เลือก "ถ่ายรูปใหม่" หรือ "เลือกจากคลังภาพ"
  3. รูปภาพจะถูกแนบในบันทึกทันที
  4. แตะค้างที่รูปเพื่อลบออกหากต้องการ

ครั้งแรกที่ใช้งาน แอปจะขอสิทธิ์เข้าถึงกล้อง/คลังภาพ กด "อนุญาต" เพื่อใช้ฟีเจอร์นี้

วิธีบันทึกเสียงแทนการพิมพ์ทำอย่างไร? ▾
  1. ขณะเขียนบันทึก แตะปุ่มไอคอน 🎤 ไมโครโฟน
  2. แตะปุ่ม "เริ่มบันทึกเสียง" แล้วพูดได้เลย
  3. แตะ "หยุด" เมื่อพูดเสร็จ
  4. ไฟล์เสียงจะถูกแนบในบันทึก สามารถเล่นซ้ำได้ตลอด

ครั้งแรกที่ใช้งาน แอปจะขอสิทธิ์เข้าถึงไมโครโฟน กด "อนุญาต" เพื่อใช้ฟีเจอร์นี้

🔍 ค้นหาและดูบันทึกเก่า
วิธีค้นหาบันทึกเก่าจากคำสำคัญ? ▾
  1. ไปที่แท็บ "ค้นหา" ที่แถบด้านล่าง
  2. พิมพ์คำสำคัญที่ต้องการในช่องค้นหา เช่น "งานบวช" "หลาน" "เที่ยวทะเล"
  3. แอปจะแสดงบันทึกทั้งหมดที่มีคำนั้น
  4. แตะที่บันทึกเพื่อเปิดอ่าน
ดูบันทึกในรูปแบบปฏิทินทำอย่างไร? ▾

แตะแท็บ "ปฏิทิน" ที่แถบด้านล่าง คุณจะเห็นปฏิทินรายเดือน วันที่มีบันทึกจะมีจุดสีเขียวกำกับ แตะที่วันใดก็ได้เพื่อดูบันทึกของวันนั้น

ดูสรุปอารมณ์รายสัปดาห์หรือรายเดือนได้ที่ไหน? ▾

แตะแท็บ "สรุป" ที่แถบด้านล่าง สามารถเลือกดูได้ทั้งแบบรายวัน รายสัปดาห์ และรายเดือน จะเห็นภาพรวมอารมณ์ความรู้สึกและจำนวนบันทึกในช่วงเวลานั้น

⚙️ การตั้งค่า
วิธีปรับขนาดตัวอักษรให้ใหญ่ขึ้น? ▾
  1. แตะแท็บ "ตั้งค่า" ที่แถบด้านล่าง
  2. เลื่อนหาหัวข้อ "ขนาดตัวอักษร"
  3. เลื่อน Slider หรือแตะปุ่ม + เพื่อเพิ่มขนาด
  4. ตัวอย่างข้อความจะแสดงให้เห็นทันที
วิธีตั้งการแจ้งเตือนให้เขียนบันทึกทุกวัน? ▾
  1. ไปที่ "ตั้งค่า" แล้วเลือก "การแจ้งเตือน"
  2. เปิดสวิตช์ "เตือนเขียนบันทึกประจำวัน"
  3. เลือกเวลาที่ต้องการให้แจ้งเตือน เช่น 20:00 น.
  4. กด "บันทึก"

ครั้งแรก แอปจะขอสิทธิ์การแจ้งเตือน กด "อนุญาต" เพื่อเปิดใช้งาน

💾 ข้อมูลและความปลอดภัย
ถ้าลบแอปออก บันทึกทั้งหมดหายไปด้วยไหม? ▾

หากลบแอปออกจากเครื่อง ข้อมูลทั้งหมดในแอปจะถูกลบออกด้วยอย่างถาวร ยกเว้นในกรณีที่คุณมี iCloud Backup เปิดใช้งานอยู่ — ข้อมูลจะถูกกู้คืนอัตโนมัติเมื่อติดตั้งแอปใหม่และล็อกอิน Apple ID เดิม

สำรองข้อมูลได้ไหม? ทำอย่างไร? ▾

สำรองข้อมูลได้ผ่าน iCloud Backup ของ Apple ครับ/ค่ะ วิธีเปิดใช้งาน:

  1. ไปที่ การตั้งค่า (Settings) บน iPhone
  2. แตะชื่อของคุณ → iCloud
  3. แตะ iCloud Backup
  4. เปิดสวิตช์ "สำรองข้อมูล iCloud"

หลังจากนั้น iPhone จะสำรองข้อมูลอัตโนมัติเมื่อเชื่อมต่อ Wi-Fi และที่ชาร์จ

ข้อมูลของฉันปลอดภัยไหม? มีคนอื่นเห็นได้ไหม? ▾

ปลอดภัยมากครับ/ค่ะ ข้อมูลทั้งหมดเก็บอยู่ในเครื่องของคุณเท่านั้น ไม่มีการส่งออกสู่อินเทอร์เน็ต ผู้พัฒนาก็ไม่สามารถเข้าถึงบันทึกของคุณได้เลย อ่านรายละเอียดเพิ่มเติมได้ที่ นโยบายความเป็นส่วนตัว

ทำไมแอปถึงขอสิทธิ์เข้าถึงกล้องและไมโครโฟน? ▾

กล้องใช้สำหรับถ่ายรูปแนบในบันทึก และไมโครโฟนใช้สำหรับฟีเจอร์บันทึกเสียง ทั้งหมดทำงานในเครื่องเท่านั้น ไม่มีการส่งรูปหรือเสียงไปที่ใด หากไม่ต้องการใช้ฟีเจอร์เหล่านี้ สามารถกด "ไม่อนุญาต" ได้ ฟีเจอร์อื่นๆ ยังใช้งานได้ปกติ
