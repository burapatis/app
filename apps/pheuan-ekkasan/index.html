ทำอะไรได้บ้าง?

ครบทุกฟังก์ชันที่ต้องการ ใช้งานง่าย ไม่ซับซ้อน

📋

บันทึกรายการ

เพิ่มรายการใหม่ง่ายๆ ระบุชื่อ หมวดหมู่ วันครบกำหนด และหมายเหตุ มีการยืนยันก่อนลบเพื่อป้องกันลบผิด

🔔

เตือนล่วงหน้า

ตั้งแจ้งเตือนล่วงหน้าก่อนถึงวันครบกำหนด เช่น 90, 30, 14, 7 หรือ 3 วัน เลือกได้มากกว่าหนึ่งช่วงต่อรายการ

🔍

ค้นหาและกรอง

ค้นหาชื่อรายการ กรองตามหมวดหมู่ หรือดูรายการที่ใกล้ครบกำหนด แสดงจำนวนผลลัพธ์ชัดเจน

📤

ส่งออก CSV / PDF

ส่งออกรายการเป็น CSV สำหรับ Excel/Sheets หรือ PDF สำหรับดูและส่งต่อ รองรับภาษาไทย (UTF-8 BOM)

🔒

ข้อมูลอยู่ในเครื่อง

ไม่ต้องสมัครสมาชิก ไม่ต้อง Login ข้อมูลทั้งหมดเก็บในเครื่องของคุณ ไม่มี Cloud ไม่มี Backend

📵

ใช้ได้ออฟไลน์

ใช้งานได้เต็มรูปแบบโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ทั้งบันทึก เตือน ค้นหา และส่งออก

📊

Dashboard ภาพรวม

หน้าหลักแสดงภาพรวมรายการทั้งหมด เห็นได้ทันทีว่ารายการไหนใกล้ครบกำหนดบ้าง

✏️

แก้ไขได้ทุกเมื่อ

แก้ไขรายการได้ตลอดเวลา แอปปรับเวลาแจ้งเตือนให้อัตโนมัติ มี dialog ป้องกันออกโดยไม่บันทึก

⚙️

ตั้งค่าครบครัน

ทดสอบการแจ้งเตือน ล้างข้อมูลทั้งหมดได้ด้วยตัวเอง และดูข้อมูลสำคัญเกี่ยวกับความเป็นส่วนตัว
