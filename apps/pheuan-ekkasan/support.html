💬 ความช่วยเหลือ

คำถามที่พบบ่อยและวิธีใช้งานเพื่อนเตือนเอกสาร

หัวข้อด่วน

🚀 เริ่มต้นใช้งาน 📋 เพิ่ม/แก้ไข/ลบรายการ 🔔 การแจ้งเตือน 🔍 ค้นหาและกรอง 📤 ส่งออก CSV/PDF 💾 ข้อมูลและความปลอดภัย 📧 ติดต่อเรา
📌 หมายเหตุ: เพื่อนเตือนเอกสารเป็นเครื่องมือช่วยบันทึกและเตือนเท่านั้น ไม่ใช่บริการทางกฎหมาย การเงิน ราชการ หรือประกันภัย การต่ออายุเอกสารทุกประเภทต้องดำเนินการกับหน่วยงานที่เกี่ยวข้องด้วยตนเอง
🚀 เริ่มต้นใช้งาน
เปิดแอปครั้งแรกต้องทำอะไร?▾
  1. เปิดแอปเพื่อนเตือนเอกสารจาก App Store หรือ TestFlight
  2. อ่านข้อตกลงการใช้งานสั้นๆ แล้วยืนยัน
  3. แตะปุ่ม "เพิ่มรายการ" เพื่อเริ่มบันทึกรายการแรก
  4. ไม่ต้องสมัครสมาชิกหรือ Login — ใช้ได้เลย
ต้องเชื่อมต่ออินเทอร์เน็ตไหม?▾

ไม่จำเป็นเลยครับ/ค่ะ ใช้งานได้ออฟไลน์เต็มรูปแบบ ทั้งบันทึก แก้ไข ค้นหา รับการแจ้งเตือน และส่งออก ทุกอย่างทำงานในเครื่องทั้งหมด

📋 เพิ่ม/แก้ไข/ลบรายการ
วิธีเพิ่มรายการใหม่ทำอย่างไร?▾
  1. แตะปุ่ม "+" หรือ "เพิ่มรายการ" บนหน้าหลัก
  2. กรอกชื่อรายการ เช่น "พ.ร.บ. รถยนต์ทะเบียน xxxx"
  3. เลือกหมวดหมู่ที่เหมาะสม
  4. เลือกวันครบกำหนด
  5. เลือกจำนวนวันที่ต้องการเตือนล่วงหน้า
  6. เพิ่มหมายเหตุหากต้องการ แล้วกด "บันทึก"

หากกดกลับโดยยังไม่บันทึก แอปจะแสดง dialog ถามก่อนออกเสมอ

บันทึกโดยไม่ตั้งเตือนล่วงหน้าได้ไหม?▾

ได้ครับ/ค่ะ หากไม่เลือกวันเตือนล่วงหน้า แอปจะแสดง dialog ยืนยันก่อน หากยืนยัน แอปจะบันทึกรายการโดยไม่มีการแจ้งเตือน

วิธีแก้ไขและลบรายการ?▾

แก้ไข: แตะที่รายการเพื่อเข้าหน้ารายละเอียด แตะ "แก้ไข" แก้ไขข้อมูล แล้วกด "บันทึก" แอปจะอัปเดตการแจ้งเตือนให้อัตโนมัติ

ลบ: เข้าหน้ารายละเอียด แตะ "ลบรายการ" แอปจะแสดง dialog ยืนยันพร้อมชื่อรายการก่อนเสมอ

🔔 การแจ้งเตือน
ตั้งเตือนล่วงหน้าได้กี่วันบ้าง?▾

สามารถเลือกได้หลายช่วง เช่น 90, 60, 30, 14, 7 หรือ 3 วันก่อนถึงวันครบกำหนด และเลือกได้มากกว่าหนึ่งช่วงต่อรายการ เช่น เตือนทั้ง 30 วันและ 7 วันก่อน

แจ้งเตือนไม่มา ทำอย่างไร?▾
  1. ตรวจสอบสิทธิ์แจ้งเตือน: การตั้งค่า → เพื่อนเตือนเอกสาร → การแจ้งเตือน → เปิด
  2. ตรวจสอบว่าไม่ได้เปิด Focus Mode หรือ Do Not Disturb
  3. ลองใช้ "ทดสอบการแจ้งเตือน" ใน ตั้งค่า ของแอป
  4. หากยังไม่มา ลองปิด-เปิดแอปใหม่

หมายเหตุ: การแจ้งเตือนอาจไม่ตรงเวลาเป๊ะในบางเครื่องขึ้นอยู่กับระบบปฏิบัติการ

🔍 ค้นหาและกรอง
วิธีค้นหาและกรองรายการ?▾

แตะไอคอนค้นหาบนหน้าหลัก พิมพ์ชื่อรายการที่ต้องการ แอปจะแสดงผลลัพธ์พร้อมจำนวนรายการ หรือใช้ฟีเจอร์กรองเพื่อดูเฉพาะหมวดหมู่ที่ต้องการ หรือรายการที่ใกล้ครบกำหนด

📤 ส่งออก CSV/PDF
วิธีส่งออกข้อมูลเป็น CSV หรือ PDF?▾
  1. ไปที่หน้าหลักหรือแท็บ "ส่งออก"
  2. เลือกรูปแบบ: CSV (Excel/Sheets) หรือ PDF (ดูและส่งต่อ)
  3. แตะ "ส่งออก" — ระบบจะเปิดหน้าต่าง Share ของ iOS
  4. เลือกปลายทาง เช่น บันทึกลงเครื่อง ส่ง LINE หรืออีเมล
⚠️ ไฟล์ที่ส่งออกมีข้อมูลรายการทั้งหมด หากแชร์ให้ผู้อื่น ผู้รับจะเห็นข้อมูลในไฟล์ได้ทั้งหมด
ไฟล์ CSV เปิดใน Excel แล้วภาษาไทยแสดงผิด?▾

ไฟล์ CSV ใส่ UTF-8 BOM ไว้แล้ว หากยังแสดงผิด ให้เปิดแบบนี้:

  1. เปิด Excel แล้วไปที่ Data → From Text/CSV
  2. เลือกไฟล์ที่ส่งออก
  3. เลือก Encoding เป็น UTF-8
  4. กด Load
💾 ข้อมูลและความปลอดภัย
ถ้าลบแอป ข้อมูลหายไหม? สำรองได้ไหม?▾

ถ้าลบแอปโดยไม่มี iCloud Backup ข้อมูลจะหายถาวร วิธีสำรอง: เปิด iCloud Backup ที่ การตั้งค่า → ชื่อของคุณ → iCloud → iCloud Backup → เปิดใช้งาน

วิธีล้างข้อมูลทั้งหมดในแอป?▾

ไปที่ ตั้งค่า → ล้างข้อมูลทั้งหมด แอปจะแสดง dialog ยืนยันก่อนเสมอ เมื่อยืนยัน ข้อมูลและการแจ้งเตือนทั้งหมดจะถูกลบ แอปจะแสดง empty state บนหน้าหลัก

แอปยืนยันข้อมูลเอกสารจริงได้ไหม?▾

ไม่ได้ครับ/ค่ะ เพื่อนเตือนเอกสารเป็นเพียงแอปบันทึกและเตือนตามข้อมูลที่คุณกรอกเอง ไม่ได้เชื่อมต่อกับระบบราชการ บริษัทประกัน หรือหน่วยงานใดๆ ความถูกต้องของวันครบกำหนดขึ้นอยู่กับข้อมูลที่คุณกรอก
